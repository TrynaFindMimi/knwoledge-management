# PROFORMA INF-009 — Servidor Local On-Premise (Alternativa)

**Fecha:** 30/08/2026
**Concepto:** Servidor fisico en oficina Buffet (air-gap para maxima privacidad victimas)

| Concepto | Costo |
|----------|-------|
| Servidor (i5 16GB 512GB SSD) | Bs. 8,000 - 12,000 (unico) |
| Servidor (Xeon 32GB 1TB) | Bs. 15,000 |
| Energia | Bs. 400-600 /mes |
| Internet dedicado (10 Mbps) | Bs. 250 /mes |
| Mantenimiento anual | Bs. 1,500 /anio |

**Pros:** Datos no salen de Bolivia, control total.
**Contras:** Requiere admin local, UPS, backups manuales, sin CDN, disponibilidad depende de oficina. Recomendado solo si Buffet exige soberania de datos.
